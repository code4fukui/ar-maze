# AR Maze

> 日本語のREADMEはこちらです: [README.ja.md](README.ja.md)

A 3D maze visualized in augmented reality (AR) using Three.js and egxr.js.

## Demo
View the demo at https://code4fukui.github.io/ar-maze/

## Features
- Generates a random maze using a depth-first search algorithm
- Displays the maze in 3D using Three.js
- Allows the user to navigate the maze in augmented reality using egxr.js

## Requirements
- A modern web browser with WebGL support

## Usage
1. Open the `index.html` file in a web browser.
2. Use the arrow keys to navigate the maze.
