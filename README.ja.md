# AR Maze

Three.jsとegxr.jsを使用して拡張現実（AR）で可視化された3D迷路です。

## デモ
デモはこちらでご覧いただけます: https://code4fukui.github.io/ar-maze/

## 機能
- 深さ優先探索アルゴリズムを使用したランダムな迷路の生成
- Three.jsを使用した3Dでの迷路の表示
- egxr.jsを使用し、拡張現実（AR）空間内で迷路の探索が可能

## 要件
- WebGLをサポートするモダンなWebブラウザ

## 使い方
1. Webブラウザで `index.html` ファイルを開きます。
2. 矢印キーを使用して迷路内を移動します。
